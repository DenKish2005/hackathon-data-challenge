# Проверка Backend Foundation — 7 ноября 2026

Проверено в Windows, Python 3.12.10, Node 24.16.0,
FastAPI 0.162.0, SQLAlchemy 2.1.8.

| Проверка | Фактический результат |
| --- | --- |
| Полный `pytest -q --tb=short` | **119 passed, 1 skipped**, 30.36 s |
| `ruff check src tests examples` | Успешно |
| `ruff format --check src tests examples` | 70 файлов, успешно |
| Python wheel (`python -m build --wheel --no-isolation`) | Успешно |
| `npm ci --no-audit --no-fund`, `npm run build` в frontend | Успешно, 1580 модулей |
| `docker compose -f compose.foundation.yml config --quiet` | Успешно |
| `git diff --check` | Успешно |

Для общего pytest временно запущен имеющийся локальный Redis 5.0.14.1 на loopback-порту
6387, `TEST_REDIS_URL=redis://127.0.0.1:6387/15`. Каждый тест использует отдельный namespace.
Без Redis первый общий прогон имел 41 ошибку подготовки старых TokenOps-тестов;
после запуска Redis они прошли. CI репозитория использует Redis 7.4.
Новый backend и его тесты Redis не требуют.

TestClient проверил `/docs`, OpenAPI-контракты, CORS, импорт 65 синтетических записей,
распределение каналов/языков, фильтрацию, версии чек-листов, задания, mock-результаты,
апелляции, историю и сохранение после закрытия/повторного открытия приложения.
Отдельно проверены отмена работающего задания при shutdown и восстановление при следующем
lifespan, повторные запросы, ошибки и таймауты, лимит параллелизма, смена модели/промпта/
текста/версии, проверка ссылок на сообщения и точных цитат существующего AI-контракта.

Пропущен только интеграционный тест с реальным DEV JSON: локальный файл не предоставлен.
Его можно включить через `CQA_TEST_DEV_FILE`. Синтетическая фикстура из 65 записей не
выдаётся за реальные 1268 сообщений DEV. Официальных PDF в рабочем репозитории не было;
использованы переданная спецификация и уже существующий чек-лист.

В тестах есть одно предупреждение зависимости Starlette о будущем переходе TestClient
с httpx на httpx2. На результат выполнения оно не повлияло.

Реальные запросы Groq/Ollama и организаторов не выполнялись; модель не загружалась,
реальные разговоры не передавались третьим сторонам. Точность оценивания не измерялась.
Docker-образ не собирался и контейнер не запускался: локальный Docker Desktop engine
недоступен. Проверена структура Compose и отдельно сборка Python wheel.
Browser smoke не запускался: frontend не изменялся; проверена его production-сборка.
Новый REST API ещё не подключён к существующему браузерному workspace — граница интеграции
описана в [контрактах](cqa-backend.md).
